# build/host — build & boot from a non-Debian host

Helper scripts for building and running Vitruvian from a host that is **not**
Debian (tested on Ubuntu 26.04, glibc 2.43, gcc 15, CMake 4.2). The host
compiles against a Debian-trixie **chroot**, so the resulting image runs
regardless of the host's library versions.

Each script derives the repo root from its own location (`build/host/` → repo
root), so they work for anyone after `git clone` — nothing to edit.

## Scripts

| Script            | What it does                                   | sudo | run as root? |
|-------------------|------------------------------------------------|------|--------------|
| `install-deps.sh` | installs all build dependencies (apt)          | —    | YES          |
| `build-iso.sh`    | chroot (debootstrap) + `bake build` → ISO      | yes¹ | NO           |
| `boot.sh`         | `bake boot` → boots the ISO in QEMU/KVM        | no²  | NO           |

¹ The script requests sudo **itself**, only where needed (apt, debootstrap
  inside `bake`). **Do not run it under `sudo`** — the output files would end up
  owned by root.
² You only need to be in the `kvm` group (`sudo usermod -aG kvm $USER`, then log
  back in).

`install-deps.sh` is the exception: it installs system packages, so it **must**
run as root.

## Usage

From the repo root, once (as root) to get the dependencies, then as a normal user:

```sh
sudo bash build/host/install-deps.sh   # installs all apt dependencies
bash build/host/build-iso.sh           # builds the ISO (a few minutes, downloads ~hundreds of MB)
bash build/host/boot.sh                # boots the ISO in QEMU (graphical window)
```

Serial console to the terminal (handy for boot debugging):

```sh
bash build/host/boot.sh --enable-console-stdout
```

## Environment variables

| Variable | Default | Meaning                                          |
|----------|---------|--------------------------------------------------|
| `ARCH`   | `amd64` | Target architecture → build tree `generated.$ARCH` |

```sh
ARCH=arm64 bash build/host/build-iso.sh
```

## Prerequisites

- **Build dependencies** installed on the host — run `install-deps.sh` (below).
  It pulls a curated base (toolchain / image / QEMU) plus the library `-dev`
  packages listed in `build_deps.txt` (generated by `configure` from
  `build/deps.cmake`), and handles the Ubuntu `libgbm-dev`/kisak PPA conflict.
  Because it reads `build_deps.txt` when present, run `./configure` once and
  re-run `install-deps.sh` to catch any library deps added since.
- A **configured build tree** `generated.$ARCH/` (see `configure`).
- For `boot.sh`: `/dev/kvm` and membership in the `kvm` group.

## Notes

- The ISO is looked up under `generated.$ARCH/{image_tree,output}/`.
- `bake` is a wrapper around `build/scripts/bake.sh` (`clean` / `build` / `boot`).
- A Debug build enables an in-image SSH server (root:live) and an aggressive
  kernel cmdline (`panic_on_warn=1`) — good for development, not for production.
