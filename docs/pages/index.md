# Overview

Build instructions, API references, and technical docs for VitruvianOS.

Vitruvian is a Linux-based operating system inspired by BeOS. It runs the BeOS/Haiku desktop and API on a Linux kernel, with custom kernel modules (Nexus) providing the missing BeOS-style system services.

## Legacy Documentation

- [The Be Book](https://www.haiku-os.org/legacy-docs/bebook/index.html): The original BeOS API reference, maintained by the Haiku project. This is the primary reference for the API Vitruvian targets.
- [Practical File System Design by Dominic Giampaolo](https://www.nobius.org/dbg/practical-file-system-design.pdf): The book behind the Be File System (BFS). Covers attribute-based filesystem design and the indexing model that powers live queries.
- [The BeOS Bible by Scot Hacker](https://archive.org/details/beosbible0000hack): A comprehensive guide to BeOS for users and developers. Covers the desktop environment, applications, and the design philosophy that Vitruvian carries forward.
- [Porting UNIX Applications to BeOS](https://archive.org/details/portingunix00beos): A practical guide to adapting POSIX/UNIX software for BeOS: threading models, filesystem differences, messaging, API mapping. Directly relevant to porting work on Vitruvian.
